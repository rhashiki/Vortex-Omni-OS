# Vortex OmniOS

Sistema operacional livre em desenvolvimento. Este repositório está em fase de preparação da Build 01 (OmniFoundation).

Nenhuma imagem inicializável, instalação ou homologação foi concluída.

## Princípios
- Software livre/open source em todos os componentes distribuídos oficialmente.
- Segurança por padrão e liberdade administrativa do proprietário.
- Sem serviços pagos obrigatórios.
- Builds e testes independentes; não utilizar GitHub Actions.

Consulte `docs/ROADMAP.md` e `security/LICENSING_POLICY.md` na branch de desenvolvimento.
