# Política de software livre

O Vortex OmniOS distribui apenas componentes cujas licenças permitem uso, modificação e redistribuição. Dependências, firmwares, marcas, recursos gráficos, modelos e suas licenças devem ser auditados antes de empacotar.

Software proprietário de terceiros poderá ser instalado pelo usuário, mas não será incluído nas imagens oficiais livres.

Projetos upstream ainda não foram homologados. Sem serviços pagos obrigatórios. GitHub Actions não deve ser utilizado.
